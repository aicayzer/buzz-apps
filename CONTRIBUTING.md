# Contributing

Fixes and new apps are welcome as pull requests. Suggest apps through [Issues](https://github.com/aicayzer/buzz-apps/issues). Open a proposal issue before substantially changing existing behaviour so scope and compatibility can be agreed first.

App contributors become maintainers of their accepted app, including its documentation, tests and provider changes. Repository maintainers retain responsibility for shared infrastructure and releases. Add the app maintainer to `CODEOWNERS` as part of the contribution.

Start with the [contributor guide](docs/contributing.md). Keep personal configuration, deployment details and credentials outside the repository. Report vulnerabilities using the [security policy](SECURITY.md).
